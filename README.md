# fidodots

Arch Linux + Hyprland desktop. The wallpaper drives the whole theme: `matugen` pulls a
Material You palette from it and rewrites the colors of Hyprland, Waybar, Quickshell,
kitty, rofi, swaync, yazi, Neovim and the Zen browser in one pass.

```
~/wallpaper/ ─► wallpaper-picker.sh (rofi) ─► wallpaper.sh ─┬─► awww     (image)
                                                            ├─► mpvpaper (video)
                                                            └─► matugen ─► every app's colors
```

## Install

```bash
git clone https://github.com/f23783/fidodots.git ~/fidodots
cd ~/fidodots
./install.sh                # packages + config
./install.sh --no-packages  # config only
./install.sh --dry-run      # show the plan, change nothing
```

Run it as your normal user; it calls `sudo` for pacman. Anything it would overwrite is
moved to `~/.fidodots-backup/<timestamp>/` first. Then drop an image or `.mp4` into
`~/wallpaper/`, log into Hyprland and press `SUPER+W`.

## Keeping it in sync

The repo holds copies, not symlinks. After changing something on the machine:

```bash
./sync.sh        # live config -> repo
git diff         # review
git commit -am "..." && git push
```

`MANIFEST` lists every tracked path, `EXCLUDES` what `sync.sh` skips (backups, legacy
scripts, generated files). Home paths are stored as `/home/__USER__/` and expanded on install.

## What's inside

| Path | What |
|---|---|
| `config/hypr` | Hyprland, hyprlock; `colors.conf` is generated by matugen |
| `config/waybar` | Top bar; the AI usage module talks to Quickshell over IPC |
| `config/quickshell` | QML widgets: clock panel, power menu, Wi-Fi, Bluetooth, AI usage popup |
| `config/matugen` | Templates for every themed app |
| `config/{kitty,rofi,swaync,swayosd,yazi,nvim,btop}` | Apps |
| `config/cliphist` | Clipboard history settings |
| `local/bin` | Clipboard menu, wallpaper picker, Wi-Fi control, headset battery, TTS |
| `home/wallpaper.sh` | Applies a wallpaper and regenerates the palette |

## Keybinds

`SUPER` is the main modifier.

| Keys | Action |
|---|---|
| `SUPER+Q` | Terminal (kitty) |
| `SUPER+C` | Close window |
| `SUPER+E` | File manager (yazi) |
| `SUPER+R` | App launcher (rofi) |
| `SUPER+TAB` | Window switcher |
| `SUPER+V` | Clipboard history |
| `SUPER+CTRL+V` | Toggle floating |
| `SUPER+W` | Wallpaper picker |
| `SUPER+N` / `SUPER+SHIFT+N` | Wi-Fi / Bluetooth panel |
| `SUPER+B` | Headset battery |
| `SUPER+L` | Lock |
| `SUPER+M` | Power off / exit |
| `SUPER+1..0` | Workspace; add `SHIFT` to move the window |
| `SUPER+S` | Scratchpad workspace |
| `Print` | Region screenshot to clipboard |

## Notes

- Clipboard history lives in RAM (`/run/user/<uid>`) and is gone after reboot. Entries
  that password managers flag are never stored.
- The monitor block in `hyprland.conf` matches a laptop panel plus one HDMI screen at
  1920x1080@144; adjust it for your hardware.
- The env block sets NVIDIA variables. Remove them on AMD or Intel.
- `XF86Calculator` calls a personal speech-to-text tool that isn't in this repo; the bind
  does nothing without it.
